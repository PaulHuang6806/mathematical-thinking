# 数学游戏盒数字化设计方案
## ——基于朱瑶《幼小衔接数学游戏盒》54 张数学牌 + 40 个玩法的全面设计

> 依据材料：`数学游戏/致大朋友和小朋友《幼小衔接数学游戏盒》学习课件`（PDF 33 页 + PPTX 69 页，牌面逐张识读）
> 设计原则：由易到难、玩中学、以评促学（金/银拇指）、情境融入、直观操作、游戏互动

---

## 一、产品定位

把实体《数学游戏盒》完整数字化为网页应用：**54 张牌 = 54+ 个交互游戏**，按五大部分组织成"五大馆"，
每馆内按认知发展**三级难度**（入门 → 进阶 → 挑战）递进，配套金拇指/银拇指成就体系（对应实体特殊牌）。
适合 3-7 岁（幼小衔接全程），可单人自玩、亲子同玩。

保留现有四模块（数感/几何/逻辑/计算）作为"快速入口"，新体系完整覆盖游戏盒内容。

## 三、由易到难的三级体系（认知发展依据）

**L1 入门（3-4 岁，小中班）**——直接感知、具体操作
- 计数 1-5/1-10、认数字符号、比较多少、大小长短粗细
- 认基本图形与立体图形（球体）、二等分、简单模式（ABAB）
- 整点（1-6 点）、上下前后方位、四季
- 全部具体图案呈现，无抽象符号，无时间压力

**L2 进阶（4-5 岁，中班）**——半抽象过渡
- 计数到 20、相邻数、奇偶、凑十、群数、简单加减
- 四等分、图形分类、数列规律、拼合计数、集合
- 整点（7-12 点）、左右、远近、星期、作息时间
- 图案 + 数字双通道；引入少量符号（+ - =）

**L3 挑战（5-7 岁，大班-一年级）**——抽象推理
- 百数表、分解、人民币、天平/价格推理、代数启蒙、平均分
- 模式迷宫、填红方块、坐标、立体计数、月份
- 传递推理（谁最重）、守恒（面积/体积）
- 支持"跳一跳够得着"的最近发展区设计，答错走阶梯不批评

## 四、五馆结构（页面与导航）

首页五大馆卡片（替代/并列现有四模块卡片）：

## 六、与现有系统的关系

- 现有四模块（数感/几何/逻辑/计算）**保留**，映射为五馆的"快速入口"：
  数感 → 数与运算 L1、几何 → 形与集合 L1、逻辑 → 形与集合/比较 L2-L3、计算 → 数与运算 L2
- 学习记录统一（mt_sessions），报告页新增馆别统计
- 金/银拇指成就 = 现有金星体系的上层荣誉（金星=单题，拇指=关卡/累计成就）
