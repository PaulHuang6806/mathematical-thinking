# 幼儿学习科学设计说明 — Mathematical Thinking

> 本文档说明产品如何依据幼儿学习科学（发展心理学、学习科学、数学教育研究）的理论与实践要求进行设计。
> 适用年龄：4-7 岁（幼小衔接）；当前实现模块：数感（数一数 / 比一比）、几何（认图形 / 找图形）。

## 1. 产品定位与核心依据

- 面向幼儿的数学启蒙，聚焦 **数感（Number Sense）**——大量纵向研究（Jordan et al., 2009 等）表明，入学前的数感水平是后续数学成就最强的预测指标之一，比计算速度更能预示长期表现。
- 单局 10 题、约 2-3 分钟，符合幼儿注意力的发展水平（一次活动约 5-10 分钟，需高频正反馈维持投入）。

## 2. 理论基础 → 设计落地对照表

| 理论 / 研究 | 核心要求 | 本产品的落地 |
| --- | --- | --- |
| 皮亚杰认知发展阶段（前运算期 2-7 岁） | 儿童依赖具体形象思维，不能进行抽象运算 | 全部题目用具体图案（水果/星星 emoji）呈现数量；不出现算式符号 |
| 格尔曼计数原则（Gelman & Gallistel） | 一一对应、固定顺序、基数原则、抽象原则、顺序无关原则 | 图案逐个可数、排列有序；答案即基数；图案种类随机（抽象原则：数任何东西都一样） |
| 数感与目测数感（Subitizing）研究 | 5 结构（five-structure）与十格阵（ten-frame）是公认的数感教学工具 | 数一数模式改用十格阵呈现：5 个一行，超过 5 自动第二行，视觉上支持"5 加几"的策略 |
| 维果茨基最近发展区（ZPD）+ 脚手架 | 任务难度略高于当前水平，成人/工具提供逐步撤除的支持 | ① 难度自适应：最近 5 题一次答对率 ≥100% 升档、≤40% 降档（0-2 档）；② 渐进提示链：鼓励 → 提示 → 逐个数（语音）→ 温柔揭晓 |
| 德韦克成长型思维（Dweck） | 表扬过程与努力，而非天赋（"你真努力"优于"你真聪明"） | 表扬语库全部为过程导向（"我看到了你的努力！""你越来越棒了！"），且随机多样，避免机械重复 |
| 埃里克森心理社会发展（主动性 vs 内疚，3-6 岁） | 幼儿需要成功体验；失败不应带来羞耻感 | 答错不批评、不扣分、不惩罚；重试答对仍得银星；三次未果由系统"一起完成"并正向收尾；结算永远以鼓励结束 |
| 斯韦勒认知负荷理论（Sweller） | 幼儿工作记忆容量极小：单任务、少选项、无干扰、无时间压力 | 每屏只一个任务；选项固定 3 个；无倒计时；无多余动画与装饰元素 |
| 梅耶多媒体学习原则（Mayer） | 视觉 + 听觉双通道加工，图文一致 | 每道题语音播报题干（"数一数，有几个？"），提示与揭晓也有语音；支持一键静音（尊重个体差异与场合） |
| 游戏化学习研究 | 即时反馈、清晰目标、进度可见、小步奖励 | 每题即时 ✓/✗ + 音效；进度条；金星（一次答对）/ 银星（重试答对）双轨奖励 |
| 幼儿注意力特点 | 活动短小、节奏明快 | 每局 10 题约 2-3 分钟；反馈间隔 1 秒级 |
|| Clements & Sarama 学习轨迹（形状） | 形状学习先"辨认"后"命名"，再逐步细化特征；比较特征促进抽象 | 认图形（图形→名字）、找图形（名字→图形）双向练习；图形按档位扩增（3 种基础 → 6 种 → 10 种），后半局优先用"相似图形"做干扰（圆↔椭圆↔月牙）训练特征区分 |
| 家长参与研究 | 家长了解学习过程有助于迁移与强化 | 学习报告页（本机 localStorage）：金星/银星/一次答对率/需帮助题数，无网络上传 |

## 3. 游戏机制设计

### 3.1 每题交互流程（脚手架阶梯）

```
第 1 次答对 → 金星 + 过程性表扬 → 下一题
第 1 次答错 → 鼓励（"没关系，再数一次"）→ 同一题重试
第 2 次答错 → 提示（"从左边开始，一个一个数"；比一比："数数每边的圆点"）
             数一数模式：语音逐个数 1..n（共同数）
第 3 次答错 → 系统温柔揭晓（"是 X 个，我们一起记住它"）→ 记入"一起完成" → 下一题
```

要点：错误路径**永远不以负面收尾**；"重试得银星"把坚持本身变成被奖励的行为；"一起完成"让求助也不丢脸。

### 3.2 星星规则

- 金星 ⭐：第一次就答对（掌握水平）
- 银星（灰色显示）：重试后答对（努力与坚持）
- 结算文案随金/银星组合变化，且必有正向结尾；不做排行榜、不比较他人（避免社会比较伤害 3-6 岁儿童）

### 3.3 难度自适应（最近发展区）

- 基础难度随轮次递进（数一数：3 个 → 12 个；比一比：1-5 → 1-15）
- 自适应档位 0-2：最近 5 题全部一次答对 → 升 1 档；≤2 题一次答对 → 降 1 档
- 保证题目始终"跳一跳够得着"

### 3.4 多感官与表征层次（布鲁纳：动作 → 图像 → 符号）

- 图像层：十格阵图案
- 半抽象层：比一比卡片上的圆点（可点数）
- 符号层：数字选项 / 卡片数字
- 同一数量至少两种表征同时出现，支持双通道加工

## 4. 家长参与

学习报告页（modules/report.html）：
- 汇总：练习局数、金星总数、银星总数、一次答对率
- 明细：最近 20 局的时间 / 模式 / 金星 / 银星 / 一起完成题数
- 数据仅存本机浏览器（localStorage），无任何上传，尊重儿童数据隐私

## 5. 伦理边界

- 无广告、无外部追踪、无网络依赖（断网可玩）
- 无倒计时压力、无惩罚机制、无排名比较
- 静音开关尊重环境与个体差异

## 6. 迭代路线

- 数感扩展：目测数感（快速闪现点数）、分与合（5/10 的组成）、排序与规律
- 其他模块：逻辑（找规律）、计算——沿用同一脚手架框架（几何已完成：认图形/找图形）
- 语音升级：✅ 可爱语音包（edge-tts 晓伊高音调预合成，base64 内联，任何打开方式可播）；待做：真人童声录音包
- 报告增强：✅ 智能建议（薄弱模式识别/表扬坚持/家长陪伴提示）+ 最近 10 局掌握趋势柱状图；待做：周报推送
- 家长参与：✅ 家长指南页（modules/guide.html：怎么陪玩/时间/答错应对/报告解读，入口在首页与报告页）
- PWA 化：可安装、可离线启动
